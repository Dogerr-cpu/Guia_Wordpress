# Guia_Wordpress
Es una guia para como instalar wordpress
¿Que es Wordpress?
WordPress es un sistema de gestión de contenidos (CMS) que permite crear y administrar páginas web de forma sencilla sin necesidad de saber programar
¿Que es xampp?
XAMPP es un paquete de software libre y gratuito que te permite crear un servidor web local en tu propia computadora para probar y desarrollar páginas o aplicaciones web sin necesidad de internet
